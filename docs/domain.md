# 领域约定

## 核心对象

- 机构会员
- 授权代表
- 工作语言
- 合作倡议
- 倡议修订
- 翻译稿
- 会议议程
- 会议意见
- 会议决议
- 表决规则
- 资源贡献
- 利益冲突声明
- 联合成果
- 发布记录

## 已知规则

- 翻译文本不能替代原文批准
- 代表授权必须处于有效任期
- 公开材料需完成规定确认
- 表决须满足法定人数与规定多数
- 会员暂停期间不得行使表决与签署权
- 历史签署不因任期结束或会员暂停而失效
- 成员仅可见自身承诺与授权附件
- 公众入口仅展示最终生效文本
- 联合编辑须基于最新修订稿

样例中的名称和编号仅用于说明字段关系，不能对应到现实中的个人、企业或业务记录。
