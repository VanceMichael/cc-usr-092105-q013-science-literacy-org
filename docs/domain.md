# 领域约定

## 核心对象

- 机构会员（创始单位、暂停区间）
- 授权代表（任期、授权书附件）
- 工作语言（原文与讨论译文的语言范围）
- 合作倡议 / 章程 / 联合成果（原文修订与翻译稿）
- 资源贡献（承诺、署名、授权附件）
- 利益冲突声明（议题范围与解除状态）
- 表决规则（法定人数、通过阈值、版本生效时间）
- 会议（议程、意见、代理、出席、投票、决议时间线）

## 已知规则

- 翻译文本不能替代原文批准，只用于讨论
- 代表授权必须处于有效任期，且所属机构未被暂停
- 公开材料需完成决议、原文批准与发布确认三道确认
- 法定人数基数与规则版本在投票开启时冻结，会后变化不追溯
- 一会员一票；代理须覆盖议程项、受托人在场且授权方无未解除利益冲突
- 联合修订必须基于当前首版，落后需 rebase 后重提
- 暂停、撤销授权、任期结束均不删除历史批准、签署与承诺

可运行实现见 `src/governance/`，规则落地说明见 [governance.md](governance.md)。

样例中的名称和编号仅用于说明字段关系，不能对应到现实中的个人、企业或业务记录。
