# 协作治理后台

世界公众科学素质组织第一次跨洲联合项目使用的登记册与议事后台。秘书处不再
靠邮件线程拼接答案：谁能代表机构、哪种文本生效、共同投入如何署名、成果何时
可以公开，全部由只追加事件和可重放状态给出确定答案。

## 七本登记册

| 登记册 | 维护内容 | 关键约束 |
| --- | --- | --- |
| 机构会员 `members` | 32 家创始单位、国家、创始身份、暂停区间 | 暂停只新增区间，恢复须引用已通过决议 |
| 代表任期 `representatives` | 授权代表、任期起止、授权书附件 | 任期 UTC 半开区间 `[start, end)`；撤销即时生效 |
| 工作语言 `languages` | 中、英、法、西、阿、俄六种工作语言 | 归档后不能再登记新原文/译文 |
| 倡议草案 `documents` | 章程/倡议/成果三类文件、原文修订、翻译稿 | 译文 `purpose=discussion`，永远不可批准 |
| 资源贡献 `contributions` | 资金/场馆/推广等承诺、署名、授权附件 | 代表只能登记本机构承诺；撤回保留历史 |
| 利益冲突 `coi` | 声明范围（全局或具体议题）与解除状态 | 未解除则本人与代理票均被拦截 |
| 表决规则 `rules` | 法定人数比例、通过阈值，多版本 | 版本按 `effective_from` 面向未来切换 |

会议的**议程、意见、修订、投票、决议**不单独建账，全部作为带 UTC 时刻（及
事件序号）的记录挂到议程项时间线（`RegistryState.item_thread`）上，按发生
时间排列。

## 关键规则如何落地

1. **翻译稿只服务讨论。** `submit_translation` 落库的事件固定
   `purpose="discussion"`；`propose_revision` 只接受文件的原文语言；
   `approve_original` 校验修订语言等于原文语言。翻译稿永远到不了批准通道。
2. **原文批准与发布确认必须由有效代表完成。** 两处门禁都调用
   `valid_rep(rep, at)`：代表未撤销、时刻在任期内、所属机构未暂停。批准还须
   引用已通过决议，且批准人所属会员对该决议投了赞成票。
3. **跨时区换日不改变事实。** 所有内部时刻以 UTC 存储（`clock.parse_moment`
   拒绝无时区文本）；当地日期只用于展示与议程排版（`local_date`）。
   同一时刻北京已是 3 月 3 日、圣保罗仍是 3 月 2 日，不影响任期与计票。
4. **法定人数基数在投票开启时冻结。** `vote_opened` 事件内嵌
   `rules_snapshot`（规则版本、法定人数比例、阈值、有效会员名单）。会议进行中
   暂停/恢复会员、通过新规则，都不改变已开场次的基数与计票；下一场投票才采用
   新基数与新版本。
5. **代理出席。** 代理只能授给其他机构、须覆盖具体议程项（或全场）、受托人须
   现场登记出席；授权可撤销。授权方有未解除利益冲突时，代理票同样被拦截。
   一会员一票，直接票与代理票重复都会被拒。
6. **多人联合编辑。** 修订采用乐观并发：`base_rev` 必须等于当前首版，落后即
   返回“请 rebase 后重提”；文件锁保证并发追加的事件序号连续。
7. **历史责任与签署不可变。** 事件只追加；暂停、撤销授权、任期结束都不会删除
   或改写已完成的批准、发布、承诺与投票。`RegistryState.replay(until=...)` 可
   重放任意历史时点（例如 r2 发布前公众只看得到 r1）。

## 可见性

- **成员自助视图** `views.member_dashboard(state, member_id)`：只返回本机构的
  承诺、授权书附件、代表任期、利益冲突、代理、表决与签署。其他机构的承诺与
  附件不进入响应。
- **公众入口** `views.public_catalog(state)`：只返回已完成“决议 → 原文批准 →
  发布确认”的最新生效版本（章程一份、项目倡议与成果各一组），并附批准决议号
  与发布时刻。草案、翻译稿、意见、利益冲突、附件永不出现。

## 代码布局

```
src/governance/
  clock.py    # UTC 归一化、当地日期
  store.py    # JSONL 只追加事件存储（fcntl 进程锁、幂等键）
  state.py    # 事件重放、七本登记册、as-of 快照、议程时间线
  service.py  # GovernanceBackend：全部业务规则与门禁
  views.py    # 成员视图与公众入口
  seed.py     # 32 家创始单位 / 6 种工作语言 / 首版表决规则引导
scripts/demo.py   # 端到端演示
tests/test_governance.py  # 34 个场景测试
```

## 运行

```bash
python3 scripts/demo.py                       # 端到端演示（独立临时事件库）
python3 -m unittest discover -s tests -v      # 全部测试
```

样例中的机构与个人名称均为说明性虚构名称，不对应现实主体。
