# 国际科学素质合作治理

记录国际科学素质组织的会员、议事与联合成果资料，并提供协作治理后台。

## 资料范围

`contracts/domain.schema.json` 约束交换资料的基本结构，`fixtures/domain.json` 提供一组不含真实个人信息的业务样例，`docs/domain.md` 说明领域对象与必须遵守的关系。读取模块只负责验证这些公开资料，不包含完整业务流程。

当前资料确认了以下事实：

- 组织已有来自二十一个国家的三十二家创始单位会员
- 组织依托长期大会和国际合作伙伴网络成立
- 目标包括交流合作、协同创新和科技社会互动

## 协作治理后台

`src/governance/` 是面向秘书处的治理后台，分别维护机构会员、代表任期、工作语言、倡议草案、资源贡献、利益冲突声明和表决规则；会议议程、意见、修订与决议按各自发生时间关联。设计要点：

- 翻译稿只服务讨论，原文批准和发布确认必须由有效代表完成
- 跨时区换日、代理出席、会员暂停、法定人数变化和多人联合编辑都按发生时刻结算，不改写历史签署与已承担的责任
- 成员只看到自己的承诺与授权附件，公众入口始终指向最终生效的章程、项目和成果

设计细节见 `docs/governance.md`；`python3 examples/demo.py` 演示跨洲联合项目从联合起草、代理出席、回避表决到批准发布的完整链路。

## 校验方式

在仓库根目录运行 `python3 -m unittest discover -s tests -v`。测试会读取样例并核对领域标识、对象清单与规则清单是否完整，并覆盖治理后台的关键情形（跨时区换日、代理出席、会员暂停、法定人数变化、联合编辑冲突、翻译稿边界与可见性）。
