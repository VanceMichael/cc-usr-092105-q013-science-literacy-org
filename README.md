# 国际科学素质合作治理

记录世界公众科学素质组织的会员、议事与联合成果资料，并提供第一次跨洲联合
项目使用的协作治理后台。

## 资料范围

- `contracts/domain.schema.json` 约束公开交换资料的基本结构；
  `fixtures/domain.json` 提供不含真实个人信息的业务样例；
  `docs/domain.md` 说明领域对象与必须遵守的关系。
- `src/domain.py` 只读校验上述公开资料。
- `src/governance/` 是可运行的协作治理后台：分别维护**机构会员、代表任期、
  工作语言、倡议草案、资源贡献、利益冲突声明、表决规则**七本登记册；会议议程、
  意见、修订与决议按各自发生时间关联。详见 [docs/governance.md](docs/governance.md)。

当前资料确认的事实：

- 组织已有来自二十一个国家的三十二家创始单位会员
- 组织依托长期大会和国际合作伙伴网络成立
- 目标包括交流合作、协同创新和科技社会互动

后台保证：翻译稿只服务讨论；原文批准与发布确认必须由有效代表完成；跨时区
换日、代理出席、会员暂停、法定人数变化与多人联合编辑并发时，已经承担的责任
和历史签署不被改写；成员只看到自己的承诺与授权附件，公众入口始终指向最终
生效的章程、项目和成果。

## 校验与演示

```bash
python3 -m unittest discover -s tests -v   # 领域校验 + 34 个治理场景测试
python3 scripts/demo.py                    # 端到端治理流程演示
```
